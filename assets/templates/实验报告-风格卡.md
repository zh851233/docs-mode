# 内置风格卡：实验报告

> 用途：无用户模板时的默认模板之一（用户传入模板时以用户模板为准）。

## 语言规范

- **语气**：学生/实验者第一人称可接受（"我在本实验中……""观察到……"），但不油腻、不邀功。
- **人称**：叙述用"本实验/本次操作"或第一人称；分析用客观陈述。
- **句式**：以"操作 → 现象 → 解释"的因果句为主；短句优先。
- **术语**：协议名、字段名、工具名用规范写法（TCP、SYN、seq、ack、Wireshark、Npcap）；首次出现给出中文解释。
- **数字**：端口号、序号、窗口大小等如实书写，保留原始精度（如 seq=1234567890、Window=64240）。
- **引号**：默认中文引号“ ”，结合上下文（英文文档/英文术语引用用英文引号）。

## 格式规范

- **标题编号**：中文"一、二、三"或阿拉伯"1. 2. 3."，全文统一；小节用 1.1 / （一）。
- **表格**：实验环境表（项目|配置）、数据表（序号|方向|标志|seq|ack|窗口），表格是实验数据的首选呈现。
- **图片**：真实截图优先（图注"图N 说明"在图下方）；示意图需标注"示意图"；图宽不超过版心。
- **代码/命令**：代码块标注语言；命令可复制；抓包过滤器单独成行（如 `tcp.flags.syn==1 && tcp.flags.ack==0`）。
- **强调**：**加粗** 用于关键结论与参数值；不用斜体长句。

## 思路特征

- **编排顺序**：为什么做（目的）→ 原理 → 怎么搭环境 → 怎么做（步骤）→ 看到什么（结果）→ 为什么是这样（分析）→ 学到什么（总结）。
- **步骤套路**：每步 = 操作 + 现象 + 说明；关键步骤配图。
- **分析套路**：对照原理逐项解读（字段含义 → 状态迁移 → 异常讨论），不写"结果符合预期"就结束。
- **过渡**：章节间用一句话承接（"完成抓包后，观察到的报文如下"）。

## 避免事项

- **不伪造数据**：不得编造抓包结果、测量值、截图内容。无真实数据时用示意图 + 占位框（见下）。
- 不抄教材整章原理；不写"提高动手能力"这类空话总结。
- 不出现"如图所示"却没有图；图/表必须有编号与说明。
- 不遗漏失败与调整过程——真实的问题记录比完美的假流程更有价值。
- 不用"首先/其次/最后"堆砌；用编号步骤推进。

## 截图与示意图策略（重要）

1. **有真实截图**：直接使用，图注写明"图N 显示……"，正文先引用。
2. **无真实截图但有数据**：用表格呈现数据（如三次握手的 seq/ack/标志位），或用 `make_diagrams.py` 生成时序图/流程图。
3. **两者都没有**：放"截图占位框"（带方框的占位行）+ 拍摄指引（应包含哪些字段），并明确告知用户提交前替换为真实截图。
4. **示意图必须标注**：程序生成的时序图/流程图在正文和图注里注明"示意图"，不得冒充真实抓包截图。

## 内容一致性规范（交付前必查）

同一概念、同一个量在全文中只允许一种表述；首次定义后，后文沿用，不得换名或换值。

### 易错对照表

| 易错点 | 错误写法 | 正确写法 |
|---|---|---|
| 时延 | 「报文②与①的时间差 ≈ 往返时延的一半」 | 客户端抓包时 t②−t① ≈ 一个完整 RTT；单程时延 ≈ RTT/2 |
| 序号 | 「序号从 1 开始计数」 | Wireshark 默认显示相对序号（首个映射为 0）；原始序号需取消 Relative sequence numbers 后查看 |
| 窗口 | 「窗口值 0x002」 | 区分窗口大小（Window Size）与窗口缩放因子（Window Scale），写清是哪一个 |
| 确认号 | 「ack = 对方序号」 | ack = 对方序号 + 1（SYN 占一个序号） |
| 图注 | 示意图被当成抓包截图 | 程序生成的图在图注与正文都标「示意图」 |

### 交付前一致性自检（三步）

1. 列出全文关键量：时延、序号、确认号、窗口、字数、文件大小、版本号；
2. 每个量找出全部出现位置，逐处核对表述与数值是否一致；
3. 运行 `python check_consistency.py 报告.md --strict`（脚本在 doc-tools/），高危项必须清零。

### 占位框规范（数据真实性）

- 占位框/拍摄指引里**不要写可照抄的实测值**。如需示范，写成「示例：0x0002（请以实际抓包为准）」，不要让读者误以为是真实数据。
- 数据表的「待填」列与占位框里的示例值必须明确区分；读者填表时只能填自己实测到的值。

## 结构红线（对照自检）

1. 七节齐全（目的/原理/环境/步骤/结果/分析/总结），与用户要求一致；
2. 实验环境含工具与版本；
3. 步骤可复现（命令、过滤器、参数齐全）；
4. 图/表编号连续、正文有引用、每图每表有说明；
5. 结果分析对照原理逐项解读，含异常讨论；
6. 数据真实，示意图已标注；引号风格与文档语言一致。
