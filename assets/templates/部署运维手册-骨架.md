# 内置骨架：部署运维手册

> 用途：无用户模板时的默认模板之一（用户传入模板时以用户模板为准）。
> 适用：系统部署、安装、运维、升级与故障处理手册，面向运维/实施人员。

## 文档整体组织

- 标题：`# XX系统部署运维手册`
- 元信息块：适用版本 / 更新日期 / 运维负责人（引用块）。
- 目录：按"部署 → 配置 → 日常运维 → 升级 → 故障处理"组织。

## 章节树

### 1. 系统概述
- 1.1 系统架构简述（组件图 + 一句话职责）。
- 1.2 部署形态（单机/集群/容器）与端口清单（服务 | 端口 | 协议 | 说明）。

### 2. 环境要求
- 2.1 硬件要求表（组件 | 最低配置 | 推荐配置）。
- 2.2 软件依赖表（软件 | 版本 | 用途）——含操作系统、运行时、中间件、数据库。
- 2.3 网络要求（防火墙放行清单、域名/证书）。

### 3. 安装与部署
- 3.1 全新安装：分步骤（下载 → 解压 → 配置 → 初始化 → 启动 → 验证），每步给命令。
- 3.2 初始化：数据库初始化、目录结构说明、默认账号修改（安全提醒）。
- 3.3 部署验证清单：健康检查命令/接口、日志确认。

### 4. 配置说明
- 4.1 配置文件位置与结构。
- 4.2 配置项表：配置项 | 默认值 | 说明 | 修改影响（重启/热加载）。
- 4.3 环境变量与敏感信息处理（密钥管理，不落明文）。

### 5. 日常运维
- 5.1 启停操作：启动/停止/重启命令与顺序。
- 5.2 日志管理：日志位置、级别调整、轮转策略。
- 5.3 备份与恢复：备份范围与周期、恢复演练步骤。
- 5.4 监控：关键指标（CPU/内存/磁盘/接口延迟）、告警阈值建议。

### 6. 升级与回滚
- 6.1 升级步骤：备份 → 停服（如需要）→ 替换 → 迁移 → 启动 → 验证。
- 6.2 回滚方案：回滚条件、回滚步骤、回滚后验证。

### 7. 故障处理
- 7.1 常见故障表：现象 | 可能原因 | 排查步骤 | 解决方案。
- 7.2 紧急联系方式与升级路径。

### 8. 附录
- 常用命令速查、端口与目录速查、版本兼容矩阵。

## 每节篇幅与节奏

| 章节 | 约占篇幅 | 内容密度 |
|---|---|---|
| 概述/环境 | 10% | 端口表、依赖表 |
| 安装部署 | 30% | 命令逐步，可复制 |
| 配置/日常运维 | 30% | 配置项表、备份恢复步骤 |
| 升级回滚/故障 | 30% | 步骤 + 故障表 |

## 关键规范

- 所有命令块标注环境与前置条件，复制即可运行；路径、版本与真实系统一致。
- 敏感信息（密码/token/密钥）一律用占位符 `<...>`，绝不出现真实值。
- 每步操作后给出验证方式（怎么知道成功了）。
