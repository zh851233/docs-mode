# 内置骨架：技术评审稿

> 用途：无用户模板时的默认模板之一（用户传入模板时以用户模板为准）。
> 适用：技术方案评审、设计评审、选型评审，面向评审委员会/决策者。

## 文档整体组织

- 标题：`# 方案N · 主题——技术评审稿`
- 元信息块（引用块）：项目 / 定位 / 状态 / 日期 / 版本 / 来源。
- 正文按编号章节组织，先结论后论证。

## 章节树

### 1. 决策摘要（最长章）
- 1.1 建议结论：引用块列出核心结论 + 评审决策（可用 ✅ 标记已确认项）。
- 1.2 核心架构：分层表 + 关键机制说明。
- 1.3 关键收益：bullet 列表，每条一个收益。
- 1.4 上线前置门槛：编号列表，实施前必须完成。

### 2. 范围与非目标
- 2.1 本方案覆盖 / 2.2 本方案不保证 / 2.3 产品表述（诚实标注能力边界）。

### 3. 当前数据基线（用真实数据说话）
- 3.1 已核对的仓库基线 / 3.2 计算口径 / 3.3 分区 / 3.4 与参照方案的量化对比（实测数据 + 日期）。

### 4~6. 方案设计（2~4 章，按模型组件逐块展开）
- 每块：统一表达 → 离散设计 → 参数范围；含与替代方案的对比论证。

### 7~9. 管线 / 资产 / 前端（按项目实际取舍）
- 输入 → 处理步骤 → 复杂度优化 / 推荐资产 → 元数据 → 加载校验 / 查询流程 → 返回结构 → 并发。

### 10. 评分与缺口 / 置信度与降级
- 指标定义、降级场景、置信度组成。

### 11. 与当前代码的对接
- 实际接入点 / 必须消除的重复实现 / 渲染口径。

### 12. 性能目标与测试方法
- 性能 SLO（量化）/ 测试设备 / 测试样本。

### 13. 精度验证方案
- 对照组 / 样本拆分 / 指标 / 建议验收门槛 / 误差预算。

### 14. 测试清单
- 单元测试 / 性质测试 / 集成测试 / 回归产物。

### 15. 实施与灰度路线
- 阶段 0~N，每阶段含交付物与验收标准。

### 16. 风险清单 / 17. 待确认事项 / 18. 定稿条件 / 19. 版本记录

## 每节篇幅与节奏

| 章节 | 约占篇幅 | 内容密度 |
|---|---|---|
| 决策摘要 | 1~2页 | 结论先行，引用块 + 表格 |
| 范围/基线 | 2~3页 | 数据与口径，表格为主 |
| 方案设计 | 40% | 每模块：设计 + 对比 + 参数 |
| 验证/测试/灰度 | 30% | SLO 量化、阶段表 |
| 风险/定稿/版本 | 10% | 表格 + 短节 |

## 关键规范

- 每个论断配实测数字（节点数、MB、ms、IoU 等），无数字不下结论。
- 修订处显式标注「vX.X 新增/修订」+ 日期，保留决策轨迹。
- 诚实标注边界（"估算模式""不宣称等价"）。
